## Resumo técnico
Duas mudanças em `automation/synapse.sh`:

1. **`auto_commit_artifacts()`** (linhas ~184): substituídos os caminhos fixos por um array local `paths`; se `atlas/data.js` existir no repo, ele é anexado ao array e passa a entrar no `git status`/`git add` do auto-commit. Sem o arquivo, comportamento idêntico ao anterior.
2. **Nova etapa após o relatório** (fim do script, antes de `auto_commit_artifacts`): se existir `atlas/generate.mjs` e `node` estiver no PATH, roda `node atlas/generate.mjs` regenerando o Atlas; sucesso ou falha só são logados (falha não é fatal), e o `data.js` recém-gerado é então capturado pelo auto-commit.

## Análise
- **Tipo feat**: o diff adiciona funcionalidade nova (regeneração automática do Atlas por commit) — coerente com o assunto do commit.
- **Impacto baixo**: apenas 1 arquivo, 13 inserções / 2 exclusões, tudo dentro do script de automação; nenhum código de produto afetado.
- **Breaking: não** — comportamento anterior preservado quando `atlas/` não existe ou node falta; auto-commit continua funcionando (paths originais intactos).
- **Risco de regressão baixo**: as condições de guarda (`[ -f ... ]`, `command -v node`, exit code não fatal) limitam blast radius. Único ponto observável: o `cd "$REPO_ROOT"` dentro do subshell para rodar o gerador — se o script depender do CWD anterior após esse bloco, poderia haver efeito, mas `auto_commit_artifacts` usa `git -C "$REPO_ROOT"` com caminhos absolutos, então não há dependência de CWD. Não há testes no repo para validar, então a confiança vem da inspeção do diff, não de suite automatizada (incerteza declarada).

## Nota para o cliente
Agora o mapa visual do seu projeto se atualiza sozinho a cada mudança registrada, sem que você precise fazer nada — ele sempre estará fresquinho e refletindo o estado atual.

## Recomendações
- Adicionar um log com o tempo de execução da regeneração do Atlas, para detectar commits que comecem a ficar lentos conforme o grafo cresce.
- Se o Atlas crescer muito, avaliar regenerar de forma incremental em vez de completa.
